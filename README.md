# 绿色低碳供应链评估系统

一个专注于 **评估流程** 和 **绿色低碳指标** 的供应链评估工具，帮助企业系统化地评估供应链的绿色低碳水平。

## 核心功能

- **四步评估流程**：基本信息 → 指标选择 → 指标评分 → 评估总结
- **16 项绿色低碳指标**：覆盖绿色采购、绿色生产、绿色物流、绿色仓储、管理体系、产品生命周期 6 大类别
- **灵活指标管理**：支持新增、编辑、删除指标，自定义评分参考标准
- **加权评分体系**：按指标权重计算综合得分，自动生成评估等级和改进建议
- **评估历史记录**：保存所有评估记录，支持查看详情和对比

## 快速开始

### 环境要求

- Python 3.10+
- Flask 3.0+

### 安装与运行

```bash
pip install -r requirements.txt
python3 app.py
```

浏览器访问 `http://localhost:5000` 即可使用。

## 指标体系

| 类别 | 指标数 | 示例指标 |
|------|--------|----------|
| 绿色采购 | 3 | 绿色原材料采购比例、供应商环保资质覆盖率、本地化采购比例 |
| 绿色生产 | 3 | 清洁能源使用比例、废弃物回收利用率、节能设备使用率 |
| 绿色物流 | 3 | 绿色运输方式使用比例、包装材料可回收比例、物流路线优化覆盖率 |
| 绿色仓储 | 2 | 绿色仓库认证达标率、仓储能耗达标率 |
| 管理体系 | 3 | 环境管理体系覆盖率、低碳目标设定与追踪、绿色培训与意识建设 |
| 产品生命周期 | 2 | 产品可回收设计比例、逆向物流回收率 |

## 评分等级

| 等级 | 分数范围 |
|------|----------|
| 优秀 | ≥90 分 |
| 良好 | 75-89 分 |
| 一般 | 60-74 分 |
| 待改进 | <60 分 |
