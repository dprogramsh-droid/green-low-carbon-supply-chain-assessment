# 绿色低碳供应链评估系统

面向 **链主企业** 的绿色低碳供应链评估平台，提供完整的评估闭环流程。聚焦评估流程管理和绿色低碳指标体系，不涉及具体产品碳足迹计算。

## 评估闭环流程

```
供应商录入 → 选择情景模式 → 创建评估方案 → 执行指标评分 → 生成评估结果 → 供应商评级自动更新
    ↑                                                                            |
    └────────────────────── 持续改进循环 ──────────────────────────────────────────┘
```

## 系统模块

| 模块 | 功能说明 |
|------|----------|
| **供应商管理** | 供应商全生命周期管理：基本信息、层级（一/二/三级）、状态（活跃/停用/黑名单）、绿色评级、评估历史 |
| **情景模式** | 预配置评估场景，组合指标包与打分规则，一键生成评估方案 |
| **指标管理** | 28 项绿色低碳评估指标，覆盖 8 大类别，支持自定义增删改 |
| **指标包** | 7 个预置指标包，将相关指标打包复用 |
| **打分规则** | 3 套评分规则（四级/五级/通过制），定义等级、及格线、权重模式 |
| **评估方案** | 基于情景模式，绑定供应商创建评估任务 |
| **执行评估** | 四步向导式评估流程，对指标逐项评分 |
| **评估记录** | 所有评估结果存档，含得分、评级、分类明细、改进建议 |
| **系统管理** | 平台设置、数据统计总览 |

## 关键特性

- **评估闭环**：评估结果自动回写供应商绿色评级（greenRating / latestScore / assessCount）
- **供应商为中心**：方案创建时从供应商列表选择，所有评估关联到具体供应商
- **灵活配置**：指标、指标包、规则、情景均可自定义
- **改进建议**：系统根据分类得分自动生成改进建议

## 预置数据

- **28 项指标**：绿色采购(4)、绿色生产(5)、绿色物流(4)、绿色仓储(3)、管理体系(4)、产品绿色设计(3)、逆向供应链(2)、供应商协同(3)
- **7 个指标包**：基础合规包、绿色采购包、绿色生产包、绿色物流仓储包、管理体系与协同包、产品全生命周期包、全面评估包
- **3 套打分规则**：标准四级评定、严格五级评定、准入通过制
- **5 个情景模式**：供应商准入评估、年度绿色绩效评估、制造业全链条评估、物流仓储专项评估、产品绿色设计评估
- **5 家示例供应商**

## 快速开始

```bash
pip install -r requirements.txt
python3 app.py
```

浏览器访问 `http://localhost:5000`
