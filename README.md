# 绿色低碳供应链评估系统 (GLCSA)

**Green Low-Carbon Supply Chain Assessment**

面向制造业、零售业及物流行业的综合性数字化平台，帮助企业对整条供应链进行碳排放测算、绿色绩效评估和可持续发展管理。

## 核心能力

- **供应链数据管理** — 供应商、物料、物流、能耗数据的统一采集与管理
- **碳排放核算引擎** — 基于 GHG Protocol 的 Scope 1/2/3 碳排放计算
- **绿色评估模型** — 多维度供应链绿色绩效评估（环境、经济、社会）
- **供应商评价管理** — 供应商绿色等级评定、准入与淘汰管理
- **产品碳足迹追溯** — 单产品全生命周期碳足迹计算与溯源
- **碳减排路径规划** — 减碳情景模拟与优化建议
- **报表与仪表盘** — 数据可视化、管理驾驶舱、合规报告生成
