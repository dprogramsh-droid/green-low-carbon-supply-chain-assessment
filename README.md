# 绿色低碳供应链评估系统

面向 **链主企业** 的绿色低碳供应链评估平台，提供完整的评估配置与执行流程，聚焦评估流程管理和绿色低碳指标体系，不涉及具体产品碳足迹计算。

## 核心概念

| 概念 | 说明 |
|------|------|
| **评估指标** | 单项绿色低碳评估项，如"清洁能源使用比例"、"供应商环保资质覆盖率"等 |
| **指标包** | 将相关指标打包组合，如"绿色采购包"、"绿色生产包"，便于复用 |
| **评估规则** | 定义评分等级、及格线、权重模式等判定规则 |
| **情景模式** | 预配置的评估场景，组合指标包与规则，如"供应商准入评估"、"年度绿色绩效评估" |
| **评估方案** | 基于情景模式，针对具体企业创建的评估任务 |
| **评估记录** | 方案执行评分后生成的评估结果 |

## 评估流程

```
选择情景模式 → 配置评估方案 → 执行指标评分 → 生成评估结果
```

1. **选择情景模式**：根据评估目的选择预配置的场景（如供应商准入、年度绩效、全链条评估等）
2. **配置评估方案**：填写被评估企业信息，可调整指标包组合和权重
3. **执行指标评分**：对方案中的每项指标进行打分
4. **生成评估结果**：系统自动按规则计算综合得分、评级并给出改进建议

## 预置数据

### 28 项评估指标（8 大类别）

- **绿色采购**（4项）：绿色原材料采购比例、供应商环保资质覆盖率、本地化采购比例、禁限用物质管控达标率
- **绿色生产**（5项）：清洁能源使用比例、废弃物回收利用率、节能设备使用率、单位产值能耗下降率、污染物排放达标率
- **绿色物流**（4项）：绿色运输方式使用率、包装材料可回收比例、物流路线优化覆盖率、空载率控制水平
- **绿色仓储**（3项）：绿色仓库认证达标率、仓储能耗达标率、智能仓储覆盖率
- **管理体系**（4项）：环境管理体系认证率、低碳目标设定与追踪、绿色供应链信息披露、绿色培训覆盖率
- **产品绿色设计**（3项）：产品可回收设计比例、绿色材料替代率、产品轻量化达成率
- **逆向供应链**（2项）：产品回收率、废旧物资处置合规率
- **供应商协同**（3项）：供应商绿色绩效考核覆盖率、供应商绿色能力提升计划、供应商环境违规率

### 7 个指标包

| 指标包 | 指标数 | 用途 |
|--------|--------|------|
| 基础合规包 | 6 | 供应商基本准入审查 |
| 绿色采购包 | 4 | 采购环节绿色评估 |
| 绿色生产包 | 5 | 生产制造节能减排评估 |
| 绿色物流仓储包 | 7 | 物流仓储绿色管理评估 |
| 管理体系与协同包 | 6 | 管理体系与供应商协同评估 |
| 产品全生命周期包 | 5 | 产品设计到回收评估 |
| 全面评估包 | 28 | 年度综合评估 |

### 3 套评估规则

- **标准四级评定**：优秀/良好/一般/待改进（等权模式）
- **严格五级评定**：卓越/优秀/良好/合格/不合格（加权模式）
- **通过/不通过**：仅判定准入门槛

### 5 个情景模式

- 供应商准入评估、年度供应商绿色绩效评估、制造业全链条评估、物流仓储专项评估、产品绿色设计评估

## 快速开始

```bash
pip install -r requirements.txt
python3 app.py
```

浏览器访问 `http://localhost:5000`

## 技术栈

- **后端**：Python + Flask
- **前端**：原生 HTML/CSS/JS 单页应用
- **数据存储**：JSON 文件（`data/` 目录，运行时自动创建）

## 项目结构

```
├── app.py              # Flask 主应用（API + 路由 + 数据初始化）
├── requirements.txt    # Python 依赖
├── templates/
│   └── index.html      # 前端单页应用（侧边栏导航 + 8个页面）
└── data/               # 运行时数据（自动创建，已 gitignore）
    ├── indicators.json  # 评估指标
    ├── packages.json    # 指标包
    ├── rules.json       # 评估规则
    ├── scenarios.json   # 情景模式
    ├── plans.json       # 评估方案
    └── records.json     # 评估记录
```
