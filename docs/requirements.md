# 汽车零部件行业绿色供应链管理系统 — 产品需求文档（PRD）

> **版本**: v1.0  
> **日期**: 2026-02-21  
> **适配范围**: Tier1-Tier2 供应链层级

---

## 一、项目概述

### 1.1 项目背景

随着全球碳中和目标推进及汽车行业绿色合规要求趋严（CBAM、REACH、ELV 等法规），汽车零部件供应链的绿色管理成为核心竞争力。Tier1 供应商需对自身及下属 Tier2 供应商实施全链路绿色管控，涵盖供应商分级、绿色评估、数据监控、合规目标、沟通培训、问卷管理等全业务流程。

### 1.2 项目目标

构建一套标准化、数字化的绿色供应链管理系统，实现：

- **全链路管控**：覆盖 Tier1-Tier2 供应商的绿色能力全生命周期管理
- **数据联动**：通过关联字段、自动化规则实现跨模块数据自动同步与计算
- **合规保障**：满足 ISO 14001、IATF 16949、REACH、ELV、CBAM 等法规要求
- **层级协同**：Tier1 对 Tier2 的目标下达、评估审核、整改跟进全流程在线化
- **风险预警**：绿色指标实时监控与自动预警，前置规避供应链合规风险

### 1.3 用户角色

| 角色 | 描述 | 核心权限 |
|------|------|----------|
| **系统管理员** | 企业内部绿色供应链管理负责人 | 全模块管理、配置、审批 |
| **Tier1 管理员** | Tier1 供应商内部绿色管理责任人 | 管理自身及下属 Tier2 供应商、下达目标、审核 Tier2 提交内容 |
| **Tier2 管理员** | Tier2 供应商内部绿色管理责任人 | 管理自身绿色数据、响应 Tier1 目标、提交自评报告 |
| **审核员** | 合规审查、评估负责人 | 执行审查、评估评分、整改跟踪 |
| **数据录入员** | 供应商端数据上传人员 | 上传绿色数据、提交问卷反馈 |

## 二、功能模块需求

### 模块一：供应商信息与分级管理

#### FR-1.1 供应商基础信息管理

**需求描述**：构建供应商全维度基础信息档案，作为全系统数据联动的核心枢纽。

| 需求编号 | 功能点 | 优先级 | 描述 |
|----------|--------|--------|------|
| FR-1.1.1 | 供应商档案创建 | P0 | 支持录入供应商 ID（唯一标识，格式：GREEN-SUP-XXX）、公司名称、所属行业、供应商层级（Tier1/Tier2）、联系人、联系方式、合作状态 |
| FR-1.1.2 | Tier1-Tier2 层级关联 | P0 | Tier2 供应商必须关联所属 Tier1；Tier1 可关联多个下属 Tier2，建立明确归属关系 |
| FR-1.1.3 | 行业分类管理 | P1 | 支持按行业分类（汽车发动机零部件/底盘零部件/电子零部件/车身及内饰零部件/新能源汽车零部件/其他） |
| FR-1.1.4 | 合作状态管理 | P1 | 支持动态更新合作状态（合作中/暂停合作/终止合作），状态变更自动记录日志 |
| FR-1.1.5 | 供应商搜索与筛选 | P1 | 支持按 ID、名称、行业、层级、合作状态等多维度检索 |

#### FR-1.2 供应商分级管理

**需求描述**：基于绿色评估结果自动进行供应商分级，支持分级标准配置与升降级管理。

| 需求编号 | 功能点 | 优先级 | 描述 |
|----------|--------|--------|------|
| FR-1.2.1 | 分级标准配置 | P0 | 支持配置分级评估维度（绿色合规能力 50%、绿色运营能力 50%）及细项权重 |
| FR-1.2.2 | 自动分级判定 | P0 | 基于评估总分自动判定分级结果：优秀(≥90)、合格(70-89)、待改进(60-69)、淘汰(<60) |
| FR-1.2.3 | Tier1/Tier2 差异化标准 | P0 | 支持 Tier1 通用标准与 Tier2 专属标准分别配置，权重、扣分规则可差异化设置 |
| FR-1.2.4 | 分级有效期管理 | P1 | 分级结果设置有效期，到期自动提醒重新评估 |
| FR-1.2.5 | 升降级记录 | P1 | 完整记录分级变动历史（变动原因、时间、审批人），形成追溯档案 |

#### FR-1.3 合规审查管理

**需求描述**：记录并管理供应商绿色合规审查全流程，实现合规问题闭环管理。

| 需求编号 | 功能点 | 优先级 | 描述 |
|----------|--------|--------|------|
| FR-1.3.1 | 审查记录创建 | P0 | 支持录入审查 ID、审查类型（年度/专项/整改复查）、审查周期、负责人、时间 |
| FR-1.3.2 | 审查范围与依据 | P0 | 支持多选审查范围（生产环保/供应链上游/产品合规/认证资质/碳足迹/VOCs）及依据（ISO 14001/IATF 16949/REACH/ELV/CBAM 等） |
| FR-1.3.3 | 合规状态判定 | P0 | 支持合规/待整改/不合规状态标记，Tier2 问题由 Tier1 牵头整改跟进 |
| FR-1.3.4 | 认证信息管理 | P1 | 支持上传认证证书附件（ISO 14001/IATF 16949/CBAM/REACH/ELV 等） |
| FR-1.3.5 | 审查周期提醒 | P1 | 支持设置审查周期和下次审查时间，逾期自动提醒 |
| FR-1.3.6 | 问题记录与整改跟踪 | P0 | 记录审查发现的合规缺口，Tier2 问题注明整改责任主体（Tier1 牵头/Tier2 自行） |

### 模块二：绿色能力评估

#### FR-2.1 绿色指标体系管理

**需求描述**：建立统一的绿色能力评估指标体系，支持 Tier1-Tier2 差异化指标配置。

| 需求编号 | 功能点 | 优先级 | 描述 |
|----------|--------|--------|------|
| FR-2.1.1 | 指标创建与分类 | P0 | 支持创建指标（ID、名称、分类：碳排放类/能源消耗类/废料回收类/VOCs治理类/轻量化材料类/合规认证类/Tier2协同类） |
| FR-2.1.2 | 层级适用范围 | P0 | 每个指标设定适用层级（Tier1/Tier2/通用）及适用行业领域 |
| FR-2.1.3 | 权重配置 | P0 | 支持指标权重设置，所有指标权重总和 100%；Tier2 专属指标权重由对应 Tier1 协同制定 |
| FR-2.1.4 | 评分等级区间 | P0 | 每个指标配置评分等级（优秀/合格/待改进），含具体量化标准 |
| FR-2.1.5 | 数据来源与单位 | P1 | 明确数据来源（自评/第三方/实时监控）及数据单位（kg CO₂/件、kWh/件、%等） |

**Tier1 通用指标示例**：
- 单位零部件碳排放量、生产能耗效率、金属废料回收率、VOCs 排放量、轻量化材料使用率、ELV 指令合规达标率、REACH 物质合规率

**Tier2 专属指标示例**：
- 上游原材料碳足迹、配套产品绿色合规率、生产过程环保设施运行达标率、供应链协同减排完成率

#### FR-2.2 绿色评估执行

**需求描述**：执行供应商定期绿色能力评估，自动计算评分、生成改进建议。

| 需求编号 | 功能点 | 优先级 | 描述 |
|----------|--------|--------|------|
| FR-2.2.1 | 评估记录创建 | P0 | 创建评估记录（ID、供应商、评估主体、周期、负责人），Tier2 评估主体默认为对应 Tier1 |
| FR-2.2.2 | 指标评分录入 | P0 | 基于指标体系逐项评分，自动匹配评分等级 |
| FR-2.2.3 | 加权总分计算 | P0 | 系统自动计算：各指标得分 × 对应权重求和，Tier2 总分同步至对应 Tier1 |
| FR-2.2.4 | 改进建议生成 | P1 | 基于评分结果自动/手动生成改进建议，Tier2 改进建议需经 Tier1 审核确认 |
| FR-2.2.5 | 改进期限与跟踪 | P1 | 设置改进期限，逾期自动提醒；Tier2 改进状态经 Tier1 确认后更新 |
| FR-2.2.6 | Tier1 审核意见 | P0 | Tier1 对 Tier2 改进方案审核（通过/需调整/驳回）并记录意见 |

### 模块三：数据收集与监控

#### FR-3.1 数据上传与验证

**需求描述**：规范供应商绿色数据上传流程，确保数据真实性和准确性。

| 需求编号 | 功能点 | 优先级 | 描述 |
|----------|--------|--------|------|
| FR-3.1.1 | 数据上传管理 | P0 | 支持录入数据上传记录（ID、供应商、上传周期：月度/季度/年度、上传时间） |
| FR-3.1.2 | 关联指标匹配 | P0 | 上传数据关联具体绿色指标，确保数据与评估指标精准匹配 |
| FR-3.1.3 | 文件与数据提交 | P0 | 支持上传附件（自评报告、碳足迹核查报告、检测报告等）及填写具体数据值 |
| FR-3.1.4 | 数据验证流程 | P0 | 验证状态（待验证/通过/不通过）、验证负责人、验证意见记录 |
| FR-3.1.5 | 重新上传机制 | P1 | 验证不通过时设置重新上传期限，逾期自动提醒 |

#### FR-3.2 实时监控与预警

**需求描述**：实时追踪核心绿色指标，自动触发预警机制。

| 需求编号 | 功能点 | 优先级 | 描述 |
|----------|--------|--------|------|
| FR-3.2.1 | 监控记录管理 | P0 | 创建监控记录（ID、供应商、监控指标），精准定位监控对象 |
| FR-3.2.2 | 实时数据同步 | P0 | 自动同步数据上传表的验证通过数据作为当前值 |
| FR-3.2.3 | 历史数据趋势 | P1 | 自动生成折线图/柱状图展示近 3/6/12 个月数据变化趋势 |
| FR-3.2.4 | 预警阈值配置 | P0 | 基于指标评分标准设置预警阈值，支持自定义调整 |
| FR-3.2.5 | 自动预警触发 | P0 | 当前值超过阈值自动更新预警状态（正常/预警/异常），触发通知 |
| FR-3.2.6 | 预警记录追溯 | P1 | 记录预警时间、通知方式（系统消息/邮件/短信）、接收人、处理进度 |

### 模块四：合规与绿色目标管理

#### FR-4.1 绿色目标管理

**需求描述**：规范 Tier1-Tier2 绿色目标的制定、分解、跟踪与评估全流程。

| 需求编号 | 功能点 | 优先级 | 描述 |
|----------|--------|--------|------|
| FR-4.1.1 | 目标创建 | P0 | 创建目标记录（ID、供应商、目标层级属性：Tier1自主/Tier1下达Tier2/Tier2自主） |
| FR-4.1.2 | Tier1-Tier2 目标关联 | P0 | Tier2 目标关联对应 Tier1，目标周期与 Tier1 协同一致 |

## 四、数据模型概要

### 核心实体关系

```
供应商基础信息表 (核心主表)
├── 1:N → 合规审查记录表
├── 1:N → 绿色评估记录表
├── 1:N → 数据上传与验证表
├── 1:N → 绿色指标监控表
├── 1:N → 绿色目标管理表
├── 1:N → 培训与反馈表
├── 1:N → 沟通记录表
├── 1:N → 问卷反馈处理表
└── Tier1 ↔ Tier2 (自关联)

绿色指标体系表 (配置表)
├── 1:N → 评估记录-指标评分详情
├── 1:N → 数据上传与验证表
├── 1:N → 实时监控表
└── 1:N → 目标管理表

分级标准配置表 (配置表)
└── → 供应商分级判定

问卷表
└── 1:N → 问卷反馈处理表
```

## 五、业务流程概要

### 流程 1：供应商准入与分级

1. 录入供应商基础信息 → 2. 设定 Tier1/Tier2 层级归属 → 3. 执行绿色能力评估 → 4. 系统自动计算总分 → 5. 自动判定分级结果 → 6. 设定分级有效期 → 7. 到期重新评估

### 流程 2：绿色数据收集与监控

1. 供应商按周期上传数据 → 2. 管理员验证数据 → 3. 验证通过数据同步至监控表 → 4. 系统对比预警阈值 → 5. 异常自动预警通知 → 6. 相关方处理预警

### 流程 3：Tier1-Tier2 目标协同

1. Tier1 制定绿色目标 → 2. 分解下达至 Tier2 → 3. Tier2 确认/反馈 → 4. Tier1 审核确认 → 5. 双方执行推进 → 6. 进度自动跟踪 → 7. 达标评估与调整

### 流程 4：合规审查闭环

1. 制定审查计划 → 2. 执行合规审查 → 3. 判定合规状态 → 4. 不合规项记录 → 5. 制定整改方案 → 6. 跟踪整改进度 → 7. 整改复查确认

## 六、验收标准

| 编号 | 验收项 | 标准 |
|------|--------|------|
| AC-01 | 供应商信息完整录入 | 所有必填字段可录入，Tier1-Tier2 关联关系正确建立 |
| AC-02 | 自动分级功能 | 基于评估总分自动输出分级结果，与配置标准一致 |
| AC-03 | 跨模块数据联动 | 供应商信息在各模块中自动关联显示，无需重复录入 |
| AC-04 | 评估总分自动计算 | 各指标得分 × 权重求和结果正确 |
| AC-05 | 目标进度自动同步 | 监控数据自动更新至目标完成进度 |
| AC-06 | 预警自动触发 | 数据超阈值时自动更新预警状态并发送通知 |
| AC-07 | Tier1 审核流程 | Tier2 提交内容可由 Tier1 在线审核并反馈 |
| AC-08 | 到期自动提醒 | 分级有效期、审查周期、改进期限等到期自动提醒 |
