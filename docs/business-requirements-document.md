## 1. 项目概述

### 1.1 项目简介

绿色低碳供应链评估系统（GLCSA）是一个面向制造业、零售业及物流行业的综合性数字化平台，旨在帮助企业对其整条供应链进行碳排放测算、绿色绩效评估和可持续发展管理。系统通过采集供应链各环节的能耗数据、物流数据、原材料数据及生产过程数据，运用科学的碳排放因子和评估模型，为企业提供量化的绿色低碳评估结果与优化建议。

### 1.2 项目愿景

构建行业领先的绿色供应链数字化评估平台，助力企业实现"双碳"目标（碳达峰与碳中和），推动供应链全链条的绿色转型升级。

### 1.3 核心价值主张

- **合规驱动**：满足国内外碳排放报告与ESG信息披露要求
- **成本优化**：识别供应链高碳环节，降低碳税/碳交易成本
- **品牌赋能**：帮助企业建立绿色品牌形象，提升市场竞争力
- **风险防控**：预警供应链环境风险，避免合规处罚与声誉损失
- **决策支撑**：以数据驱动供应链绿色化决策

## 2. 业务背景与目标

### 2.1 行业背景

- 全球气候治理进入加速期，《巴黎协定》、欧盟碳边境调节机制（CBAM）、中国"双碳"目标对企业提出更高要求
- 供应链碳排放通常占企业总排放的 70%-90%（Scope 3），是碳减排的关键领域
- ESG投资趋势驱动企业加强供应链环境信息披露
- 绿色采购、绿色物流等政策法规日趋严格

### 2.2 业务痛点

| 痛点编号 | 痛点描述 |
|---------|---------|
| BP-001 | 供应链碳排放数据分散，难以统一采集和管理 |
| BP-002 | 缺乏科学的碳排放计算模型，依赖人工估算 |
| BP-003 | 供应商绿色绩效难以量化评价，选商缺乏依据 |
| BP-004 | 碳排放报告编制耗时长、准确性低 |
| BP-005 | 无法追溯产品全生命周期碳足迹 |
| BP-006 | 缺少供应链碳减排路径规划工具 |
| BP-007 | 合规报告（如CDP、GRI、ISSB）生成能力不足 |

### 2.3 业务目标

| 目标编号 | 目标描述 | 关键指标（KPI） |
|---------|---------|----------------|
| BG-001 | 实现供应链全链条碳排放数据的自动化采集 | 数据自动采集率 ≥ 80% |
| BG-002 | 建立科学的碳排放核算与评估模型 | 核算准确率 ≥ 95% |
| BG-003 | 构建供应商绿色绩效评价体系 | 覆盖一级供应商 100% |
| BG-004 | 缩短碳排放报告编制周期 | 报告生成时间 ≤ 3个工作日 |
| BG-005 | 支持产品碳足迹追溯与认证 | 支持主要产品线 ≥ 90% |
| BG-006 | 提供碳减排路径规划与模拟功能 | 年碳减排目标达成率 ≥ 85% |
| BG-007 | 满足主流ESG与碳排放报告框架要求 | 支持 ≥ 5种国际报告标准 |

## 3. 项目范围

### 3.1 范围内（In Scope）

| 模块 | 说明 |
|------|------|
| 供应链数据管理 | 供应商信息、物料信息、物流路径、能耗数据的采集与管理 |
| 碳排放核算引擎 | 基于GHG Protocol的Scope 1/2/3碳排放计算 |
| 绿色评估模型 | 多维度供应链绿色绩效评估（环境、经济、社会） |
| 供应商评价管理 | 供应商绿色等级评定、准入与淘汰管理 |
| 产品碳足迹追溯 | 单产品全生命周期碳足迹计算与溯源 |
| 碳减排路径规划 | 减碳情景模拟与优化建议 |
| 报表与仪表盘 | 数据可视化、管理驾驶舱、合规报告生成 |
| 预警与通知 | 碳排放超标预警、合规到期提醒 |
| 系统管理 | 用户权限、组织架构、审计日志 |

### 3.2 范围外（Out of Scope）

| 内容 | 说明 |
|------|------|
| 碳交易市场接入 | 第一期不包含碳配额交易功能 |
| 生产执行系统（MES） | 不替代现有MES系统，仅采集其输出数据 |
| 财务核算 | 不包含碳资产的财务会计处理 |
| 物联网硬件部署 | 不涉及传感器等IoT硬件的采购与安装 |

### 3.3 假设与依赖

- 企业已有基础的ERP/SCM系统可提供数据源
- 碳排放因子数据库可通过公开数据获取（如IPCC、国家统计局）
- 供应商愿意配合提供相关环境数据
- 相关行业标准和法规在项目期间不发生重大变更

## 5. 功能需求

### 5.1 供应链数据管理（F-100）

#### F-101 供应商信息管理

- **描述**：建立统一的供应商档案，包含基础信息、资质证书、环境管理认证（ISO 14001、ISO 50001等）
- **功能要点**：
  - 供应商注册与资料填报
  - 供应商分级分类（按行业、规模、区域、风险等级）
  - 证书到期自动提醒
  - 供应商地图可视化展示
  - 支持批量导入/导出（Excel/CSV）
- **业务规则**：
  - 新增供应商须经审批后方可纳入合格供应商库
  - ISO 14001认证到期前90天自动预警

#### F-102 物料与BOM数据管理

- **描述**：管理原材料、零部件及BOM（物料清单）信息，关联碳排放因子
- **功能要点**：
  - 物料主数据维护（名称、类别、单位、碳排放因子）
  - BOM结构树管理
  - 物料-供应商关联关系维护
  - 碳排放因子自动匹配（基于物料类别）
  - 物料替代方案管理（低碳替代建议）
- **业务规则**：
  - 每种物料必须关联至少一个碳排放因子
  - BOM变更须触发碳足迹重新计算

#### F-103 物流与运输数据管理

- **描述**：管理供应链物流路径及运输数据
- **功能要点**：
  - 运输方式管理（公路、铁路、水运、航空、多式联运）
  - 运输路径规划与距离计算
  - 车辆/船舶/飞机能耗数据录入
  - 实际运输记录导入（与TMS系统对接）
  - 物流碳排放自动核算
- **业务规则**：
  - 运输碳排放 = 运输距离 × 货物重量 × 对应运输方式碳排放因子
  - 多式联运需分段计算后汇总

#### F-104 能源与能耗数据管理

- **描述**：采集供应链各环节的能源消耗数据
- **功能要点**：
  - 能源类型管理（电力、天然气、煤炭、柴油、可再生能源等）
  - 分工序/分设备能耗数据录入
  - 能耗数据自动导入（对接能源管理系统）
  - 能耗趋势分析
  - 绿色电力比例统计
- **业务规则**：
  - 电力碳排放因子按区域电网排放因子计算
  - 自建光伏等可再生能源视为零碳排放

### 5.2 碳排放核算引擎（F-200）

#### F-201 Scope 1 直接排放核算

- **描述**：核算企业直接控制的排放源产生的温室气体排放
- **覆盖范围**：
  - 固定燃烧源（锅炉、炉窑）
  - 移动燃烧源（自有车辆、叉车）
  - 过程排放（化学反应、制冷剂逸散）
  - 逸散排放（管道泄漏、废水处理）
- **计算方法**：
  - 排放量 = 活动数据 × 排放因子
  - 支持CO₂、CH₄、N₂O、HFCs、PFCs、SF₆、NF₃等温室气体
  - 统一折算为CO₂当量（CO₂e）
- **业务规则**：
  - 排放因子优先使用实测值，其次使用行业缺省值，最后使用IPCC缺省值
  - 所有GWP（全球变暖潜势）值参照IPCC AR6

#### F-202 Scope 2 间接排放核算

- **描述**：核算外购电力、蒸汽、供热/供冷的间接排放
- **计算方法**：
  - **基于位置的方法**：使用区域电网平均排放因子
  - **基于市场的方法**：使用供应商特定排放因子、绿证、PPA等
  - 支持两种方法并行计算与对比展示
- **业务规则**：
  - 绿色电力证书（GEC/I-REC）可用于抵扣Scope 2排放
  - 电网排放因子需定期更新（至少年度）

#### F-203 Scope 3 价值链排放核算

- **描述**：核算上下游价值链中的间接排放（供应链碳排放的核心）
- **覆盖类别**（参照GHG Protocol Scope 3标准的15个类别）：

| 类别 | 名称 | 系统支持情况 |
|------|------|------------|
| 1 | 外购商品和服务 | ✅ 第一期支持 |
| 2 | 资本货物 | ✅ 第一期支持 |
| 3 | 燃料和能源相关活动 | ✅ 第一期支持 |
| 4 | 上游运输和配送 | ✅ 第一期支持 |
| 5 | 运营中产生的废弃物 | ✅ 第一期支持 |
| 6 | 商务旅行 | ⏳ 第二期 |
| 7 | 员工通勤 | ⏳ 第二期 |
| 8 | 上游租赁资产 | ⏳ 第二期 |
| 9 | 下游运输和配送 | ✅ 第一期支持 |
| 10 | 售出产品的加工 | ⏳ 第二期 |
| 11 | 售出产品的使用 | ✅ 第一期支持 |
| 12 | 售出产品的报废处理 | ✅ 第一期支持 |
| 13 | 下游租赁资产 | ⏳ 第二期 |
| 14 | 特许经营 | ⏳ 第二期 |
| 15 | 投资 | ⏳ 第二期 |

- **计算方法**：
  - 基于供应商特定数据法（优先）
  - 基于平均数据法
  - 基于支出数据法（兜底）
  - 混合法（组合使用以上方法）

#### F-204 碳排放因子数据库

- **描述**：内置并可扩展的碳排放因子数据库
- **功能要点**：
  - 预置主流碳排放因子数据库（IPCC、GaBi、Ecoinvent、中国生命周期基础数据库CLCD）
  - 支持自定义排放因子
  - 因子版本管理与历史追溯
  - 排放因子审核流程
  - 按行业/区域/物料分类检索
- **业务规则**：
  - 自定义排放因子需经审核后方可使用
  - 系统默认使用最新版排放因子，支持回溯计算

#### F-205 碳排放核算任务管理

- **描述**：管理碳排放核算的完整生命周期
- **功能要点**：
  - 创建核算任务（指定范围、时间段、核算边界）
  - 数据采集进度跟踪
  - 核算执行与结果复核
  - 核算报告审批流程
  - 历史核算数据对比
- **业务规则**：
  - 核算结果需经至少两级审批后方可发布
  - 数据完整度低于80%时给出警告提示

### 5.3 绿色评估模型（F-300）

#### F-301 供应商绿色评分模型

- **描述**：基于多维度指标体系对供应商进行绿色绩效评分
- **评估维度**：

| 维度 | 权重(默认) | 关键指标 |
|------|-----------|---------|
| 碳排放绩效 | 30% | 单位产值碳排放、碳排放年降幅、Scope 1+2排放量 |
| 环境管理体系 | 20% | ISO 14001认证、环境管理制度、环保投入占比 |
| 资源效率 | 15% | 能源利用率、水资源利用率、原材料利用率、废弃物回收率 |
| 绿色创新 | 15% | 绿色专利数量、清洁生产技术应用、研发投入占比 |
| 合规表现 | 10% | 环保处罚记录、排污许可合规性、环评合规性 |
| 社会责任 | 10% | ESG评级、社会责任报告、社区环境贡献 |

- **功能要点**：
  - 评估维度与权重可配置
  - 支持AHP（层次分析法）辅助确定权重
  - 评分结果自动计算并可视化展示
  - 供应商绿色等级自动划分（A/B/C/D/E五级）
  - 评估结果历史趋势对比
  - 支持评估模板管理

#### F-302 供应链整体绿色评估

- **描述**：对企业整条供应链的绿色水平进行综合评估
- **评估内容**：
  - 供应链碳排放总量与碳强度
  - 绿色供应商占比
  - 绿色物流占比
  - 绿色采购占比
  - 产品平均碳足迹
  - 循环经济指标（回收率、再利用率）
- **功能要点**：
  - 供应链绿色成熟度模型（5级：初始级→可重复级→已定义级→已量化级→持续优化级）
  - 行业标杆对比
  - 差距分析与改进路径建议
  - 年度评估报告自动生成

#### F-303 产品碳足迹评估

- **描述**：计算单个产品从"摇篮到大门"或"摇篮到坟墓"的全生命周期碳足迹
- **生命周期阶段**：
  - 原材料获取（含采矿、种植等）
  - 原材料运输
  - 生产制造
  - 成品运输与配送
  - 产品使用阶段
  - 产品报废与处置
- **功能要点**：
  - 基于BOM自动展开计算
  - 支持ISO 14067产品碳足迹标准
  - 碳足迹热力图（识别高碳环节）
  - 产品碳标签生成
  - 碳足迹报告输出（支持第三方认证送审格式）
- **业务规则**：
  - 系统边界划定需符合ISO 14044/14067要求
  - 截断规则：质量占比 < 1% 且 能量占比 < 1% 的物料可忽略

#### F-304 碳减排情景模拟

- **描述**：提供碳减排路径规划与情景模拟工具
- **功能要点**：
  - 减排措施库管理（光伏安装、设备升级、运输优化、材料替代等）
  - 减排潜力自动测算
  - 多情景对比分析（保守/中等/激进方案）
  - 减排成本-效益分析
  - 减排目标跟踪与进度管理
  - 科学碳目标倡议（SBTi）路径参考
- **业务规则**：
  - 减排目标需与国家/行业/企业自身承诺对齐
  - 情景模拟时间范围支持1-30年

### 5.4 供应商评价管理（F-400）

#### F-401 评价流程管理

- **描述**：管理供应商绿色评价的完整流程
- **流程步骤**：
  1. 创建评价计划（设定评价周期、覆盖范围、评价标准）
  2. 下发评价问卷（供应商在线填报）
  3. 数据采集与核验
  4. 自动评分计算
  5. 专家评审与调整
  6. 结果发布与通知
  7. 整改跟踪（针对低分供应商）
- **功能要点**：
  - 评价问卷模板管理（支持多行业定制）
  - 供应商在线填报门户
  - 填报进度实时跟踪
  - 数据异常自动检测
  - 评价结果申诉流程

#### F-402 供应商准入与淘汰

- **描述**：基于绿色评价结果的供应商生命周期管理
- **功能要点**：
  - 绿色准入标准配置
  - 供应商绿色准入审批流程
  - 绿色评分不达标供应商自动标记
  - 供应商整改计划管理

```
[排放基线确立] ──> 基于历史碳核算数据确立基准年排放量
  │
  v
[减排措施识别] ──> 从减排措施库筛选适用措施
  │
  v
[减排潜力评估] ──> 逐项评估减排量、实施成本、实施周期
  │
  v
[情景构建]
  ├──> 保守方案（低投入、低风险）
  ├──> 中等方案（均衡投入）
  └──> 激进方案（高投入、高回报）
  │
  v
[成本效益分析] ──> 计算各方案的投资回报率、边际减排成本
  │
  v
[方案比选] ──> 管理层评审决策
  │
  v
[实施计划制定] ──> 明确责任人、时间表、资源配置
  │
  v
[执行监控] ──> 定期跟踪进度 ──> 偏差分析 ──> 纠偏
  │
  v
结束
```

### 附录B：碳排放核算公式汇总

**1. 固定燃烧排放**
```
E_combustion = Σ(AD_i × EF_i × GWP_i)
其中：
  AD_i = 第i种燃料消耗量
  EF_i = 第i种燃料的排放因子
  GWP_i = 对应温室气体的全球变暖潜势
```

**2. 外购电力排放（基于位置法）**
```
E_electricity = AD_electricity × EF_grid
其中：
  AD_electricity = 外购电量 (MWh)
  EF_grid = 区域电网排放因子 (tCO₂/MWh)
```

**3. 运输排放**
```
E_transport = Σ(D_i × W_i × EF_transport_i)
其中：
  D_i = 第i段运输距离 (km)
  W_i = 货物重量 (t)
  EF_transport_i = 运输方式排放因子 (tCO₂e/t·km)
```

**4. 产品碳足迹**
```
CF_product = Σ(E_material + E_transport_in + E_manufacturing + E_transport_out + E_use + E_disposal)
其中各项分别为原材料、入厂运输、生产制造、出厂运输、使用阶段、报废处置的排放量
```

**5. 碳排放强度**
```
CI = E_total / Output
其中：
  E_total = 碳排放总量 (tCO₂e)
  Output = 产出指标（营收/产量/面积等）
```
